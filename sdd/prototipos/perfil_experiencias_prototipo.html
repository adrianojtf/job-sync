PROTÓTIPO

Como testar

  • Mouse ou toque: arraste pela alça ⠿ (nas tecnologias, pela própria tag). Nas listas com cartões, eles se recolhem durante o arrasto.
  • Teclado: foque a alça, Espaço pega, ↑/↓ (ou ←/→ nas tags) move, Espaço solta, Esc cancela.
  • Sem arrastar: botões ↑ ↓ em cada item.
  • Editar: clique no cartão para abrir os campos.
  • Cada lista reordena só dentro dela mesma.

Decisões para o PRD

  1. Ordem manual ou por período? Proposta: manual em todas, com "Ordenar por período" como atalho (experiências, formação, certificações), sempre com desfazer.
  2. Abertura dos cartões: proposta: todos recolhidos ao abrir; item novo abre expandido; vários podem ficar abertos.
  3. Idiomas: linha única editável, sem abrir. A ordem do perfil é a do currículo.
  4. Tecnologias: hoje é um campo de texto separado por vírgula. Proposta: tags que se criam, excluem e reordenam (a ordem vale no currículo). Exige decidir se a sincronia com as skills acrescenta no fim.
  5. Persistência: a ordem é a da lista salva; sem campo novo na API. Só vale após Salvar perfil.
  6. Atenção aos índices: o endpoint que guarda conquista aprovada identifica a experiência pela posição. Reordenar sem salvar não pode fazer esse fluxo apontar para a experiência errada.
  7. Dados pessoais: ficam como um cartão recolhível, sem reordenação.
